# HỆ THỐNG THƯƠNG MẠI ĐIỆN TỬ MMENU

## 1. Giới thiệu đề tài

Đề tài: Phát triển hệ thống thương mại điện tử mMenu trong quản lý và kinh doanh dịch vụ F&B.

Dự án nghiên cứu hệ thống mMenu và vai trò của thương mại điện tử trong việc hỗ trợ quản lý, vận hành và kinh doanh nhà hàng, quán ăn.

## 2. Mục tiêu

- Tìm hiểu tổng quan về hệ thống mMenu.
- Phân tích các chức năng hỗ trợ hoạt động kinh doanh dịch vụ F&B.
- Đề xuất hướng phát triển hệ thống mMenu.

## 3. Chức năng chính

- Quản lý thực đơn.
- Hỗ trợ đặt món.
- Theo dõi và quản lý đơn hàng.
- Hỗ trợ thanh toán.
- Hỗ trợ quản lý hoạt động kinh doanh.

## 4. Tài liệu dự án

Báo cáo chi tiết được lưu trong file `BT4 - Nhóm 5.docx` tại repository này.

- Nhóm thực hiện: Nhóm 5.
